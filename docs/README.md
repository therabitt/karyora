# Karyora Documentation

Karyora is an artist portfolio and commission inquiry management application.

## Design documentation

- [Visual direction and homepage redesign brief](design/visual-direction.md): the intended public-facing design language, analysis of the current implementation, reference-site observations, non-negotiable constraints, and an implementation/verification plan.

## Agent rule

Before changing public-facing UI, read the visual direction brief and inspect the current implementation. A reference URL alone is not a complete design specification. The brief records the visual patterns to learn from and how to translate them into Karyora's own identity.

This index does not replace the technical architecture, security rules, or data-integrity requirements in `AGENTS.md`.
